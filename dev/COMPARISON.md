# 和「角球数据记录」「角球六要素」的同场对比（2026-10-28）

数据：StatsBomb 2015/16 英超、西甲、意甲、法甲 1,517 场（两个旧 app 建模和验证用的就是这批比赛）。
旧模型用它们仓库里的原始代码，按原来的“三个联赛训练、第四个联赛测试”重跑；新模型的滚球参数在拟合时**去掉了这 1,517 场**，所以三者都是样本外。

## A. 角球数据记录（同样的检查点：每半场第 9/18/30/39 分钟、下半场开始；同样的盘口）
Brier 分数，越低越准：

| | 半场大小 | 半场让球 |
| --- | --- | --- |
| 只用时间、比分 | 0.1607 | 0.1518 |
| 加记录（进入前场/禁区/传中） | 0.1598 | 0.1472 |
| 记录 + 全场预期* | 0.1581 | 0.1473 |
| **新程序** | **0.1578** | **0.1441** |

- 大小：比“加记录”低 1.25%（95% 区间 −2.0% 到 −0.4%）；和“记录+全场预期”打平（−0.2%，区间 −1.1% 到 +0.5%）。上半场新程序更准，下半场“记录+全场预期”略好。
- 让球：比旧模型最好的版本低 2.2%（95% 区间 −3.3% 到 −1.2%），上下半场都是。
- *验证里的“全场预期”用的是同一赛季其他比赛的场均（包括这场之后的比赛），实际使用时拿不到，所以这一项对旧模型偏有利。旧模型的记录在验证里来自完美的事件数据，实际是手点，误差会更大。

# 角球进球预测

赛前和滚球的角球、进球预测：给出全场/半场角球大小、角球让球、单队角球、胜平负、进球大小的概率和公平赔率；填上庄家欧赔就能算期望收益。

- 安装：用 Safari 打开这个仓库的 GitHub Pages 网址 →“分享”→“添加到主屏幕”。联网打开一次后就能离线使用。
- 赛前：选联赛和两队，最好填胜平负和大小球赔率（不填则只用球队数据）。数据库外的联赛选“其他联赛”，填联赛场均角球和赔率。
- 滚球：开球时点“开始计时”，之后只需点角球、进球、红牌；中途进入就输入当前分钟。第四官员举牌后填补时。
- 数据：内置 21 个联赛（英超到苏乙、德甲德乙、意甲意乙、西甲西乙、法甲法乙、荷甲、比甲、葡超、土超、希超）的球队评分；联网时每 12 小时自动从公开数据源下载本赛季最新赛果并在本机更新评分，也可以在“说明”页手动更新。
- 一台手机边看画中画边用：在“说明 → 显示”里选“视频浮窗留位”。
- 数据只存在设备上；和同一网域下的“角球数据记录”“角球六要素”分开存放，互不影响。

模型和回测见 app 里的“说明”页。源码和数据流程在 `dev/`。

数据来源：Football-Data.co.uk（经 xgabora/Club-Football-Match-Data 整理）、open-matchday（本赛季）、StatsBomb 与 Wyscout 公开事件数据。
